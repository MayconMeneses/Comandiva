# Referência de navegação para o cardápio do Comandiva

A referência indicada pelo usuário concentra as categorias em uma **faixa horizontal com avanço lateral**, usando miniaturas e um item por vez como ponto de entrada. Abaixo dela, os produtos da categoria aparecem em cartões compactos de duas colunas, reduzindo a necessidade de percorrer listas extensas.

Para o Comandiva, será adotado o princípio de **trilhos horizontais por categoria**, com controles de passagem lateral e cartões menores. A identidade, os textos, os produtos e os recursos visuais continuarão próprios do Comandiva; a referência é usada apenas como orientação de interação e densidade de conteúdo.
