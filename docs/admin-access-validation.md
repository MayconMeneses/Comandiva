# Validação da gestão de acessos

A prévia autenticada do painel administrativo em desktop mostrou a nova ação **Acessos administrativos** no rodapé da barra lateral, abaixo do perfil do administrador atual. O botão usa fundo opaco, borda e contraste compatíveis com o restante da navegação.

A navegação automatizada sem a sessão persistida do WebDev abriu a tela de login, o que é esperado para uma sessão de navegador independente; a prévia autenticada do projeto permanece a referência visual da conta ADM atual.
